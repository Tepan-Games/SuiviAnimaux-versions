# Suivi des animaux — versions

Téléchargements du logiciel **Suivi des animaux** (Windows 10 et 11) : suivi des animaux d'une famille
et des animaux accueillis pour une association (fiches, soins, traitements, stock, médicaments, contacts…).

Ce dépôt ne contient que les versions publiées ; le code source est privé.

## Installer

1. Ouvrez la page [**Releases**](https://github.com/Tepan-Games/SuiviAnimaux-versions/releases/latest)
   et téléchargez le fichier `SuiviAnimaux-x.y.z.zip`.
2. Décompressez-le et lancez `SuiviAnimaux.exe` (rien d'autre à installer).
3. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »
   puis « Exécuter quand même » (le logiciel n'est pas signé numériquement).

## Mises à jour

À partir de la version 1.9.0, le logiciel cherche lui-même une nouvelle version au démarrage
(une fois par jour, réglable dans **Paramètres › Mises à jour du logiciel**) et l'installe en un clic.
Les données (`%LocalAppData%\SuiviAnimaux`) sont conservées et mises à niveau automatiquement,
après une copie de sauvegarde.
